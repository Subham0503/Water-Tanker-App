# AquaConnect Full-Stack Frontend

React + Vite frontend integrated with the AquaConnect Node/Express API.

## Local run
1. Start the backend first.
2. Copy `.env.example` to `.env` and set `VITE_API_URL=http://localhost:5000/api`.
3. `npm install`
4. `npm run dev`

The UI intentionally keeps the existing customer/vendor design. Demo payment is simulated; no real payment gateway or GPS is used.
